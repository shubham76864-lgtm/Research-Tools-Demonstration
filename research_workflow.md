# Research Workflow

## Step 1: Literature Search
Search Google Scholar for relevant research papers.

## Step 2: Reference Management
Save relevant papers and organize their citation details using Zotero.

## Step 3: Report Preparation
Prepare the research report using MS Word or LaTeX.

## Step 4: Version Control
Use GitHub commits to record changes to project files.

## Step 5: Final Review
Check formatting, references, and project documentation before submission.
